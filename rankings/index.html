Artificial Analysis 让所有模型跑同一套智能指数题集,按各家 API 的输入、缓存、推理、输出 token 逐项实际计费。这是目前最接近"完成同一目标要花多少钱"的公开口径——它同时反映模型的单价和话多不多(token 效率)。

⚠ 重要前提:下表全部是「最高 effort」下的成绩与账单

AA 对推理模型采用厂商披露的最高推理强度(榜单条目标注为 Adaptive Reasoning, Max Effort;同一模型的不同档位会被列为独立条目,例如 GPT-5.6 Sol (max) 59 分与 (xhigh) 58 分)。

effort 不改变每 token 单价,改变的是一道题烧掉多少 token:高 effort 让模型花更多 token 规划、自检、返工。以 Claude Opus 5 的五档(low / medium / high / xhigh / max)为例,low 到 max 的每次成本差约 3 倍,high 约为 medium 的 2 倍。

还有第二种"堆算力"的方式:并行编排。GPT-5.6 Sol 的 Ultra 模式不是把一条思维链拉长,而是把难题分派给多个并行子代理——Terminal-Bench 2.1 从基础 Sol 的 88.8% 提升到 91.9%。它同样没有单独标价,但每个子代理各自消耗 token,一次 Ultra 运行相当于好几次普通调用。同一个模型名,跑法不同,账单可以差一个量级。

💡 因此下表是成本上限,不是日常开销。Anthropic 官方反而建议广泛使用 low/medium——FrontierCode 基准显示 Opus 5 在 medium effort 就达到编程峰值(主集 53.4%、扩展集 63.6%),再往上收益递减。日常按 medium 用,账单可能只有表中的一半,编程质量还未必更差。

「极限用量」与「会员折算价」怎么算的

※ 极限用量 = 按各家官方额度窗口满负荷折算的数量级估算。不同任务类型(补全/对话/Agent)折算差异极大,仅供比较,以官方说明为准。

会员折算价 = 月费 ÷ 极限用量,即"把额度用满时每百万 token 的成本"。用得越少单价越高;与右侧 API 标价对照,可看出会员在什么用量下开始划算。国产平台 API 价按当期汇率近似换算为美元。
