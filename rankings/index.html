「极限用量」与「会员折算价」怎么算的

※ 极限用量 = 按各家官方额度窗口满负荷折算的数量级估算。不同任务类型(补全/对话/Agent)折算差异极大,仅供比较,以官方说明为准。

会员折算价 = 月费 ÷ 极限用量,即"把额度用满时每百万 token 的成本"。用得越少单价越高;与右侧 API 标价对照,可看出会员在什么用量下开始划算。国产平台 API 价按当期汇率近似换算为美元。
