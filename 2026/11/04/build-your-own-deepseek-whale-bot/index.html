从零养一只 DeepSeek 小鲸鱼:QQ、微信、冷热记忆,还能远程帮你操作电脑

最近 QQ 群里冒出不少“小鲸鱼”:一个用 DeepSeek 当大脑、住在聊天软件里的 AI 群友。GitHub 上同名或同类的项目已经有好几个,做法各不相同。

这篇不推荐某一个现成项目,而是带你用官方和主流开源组件,自己拼一只。目标是四件事:

  1. 能在 QQ 和 微信里聊天;
  2. 有冷热两层记忆:常用的事随口就记得,久远的事需要时能翻出来;
  3. 主人能用一句自然语言远程让它帮忙操作电脑;
  4. 全程不碰非官方的账号注入,并且把“远程操作电脑”这件危险的事关进笼子里。
// 一句话摘要
  • 四个零件:大脑用 DeepSeek 官方开源的 DeepSeek Harness(DSH);嘴巴用社区插件 dsh-im 接 QQ 和微信;记忆用 dsh-fish-memory 或 dsh-mnemon;手就是 DSH 自带的命令行与文件工具。
  • QQ 和微信都走官方通道:QQ 是 QQ 开放平台的机器人,微信是腾讯开放的 iLink 个人号 Bot 接口,都是扫码绑定。
  • 冷热记忆:热记忆(人设、主人画像、约定)每轮都带上;冷记忆(过往事件、长期资料)按需检索,而且会随时间淡忘。
  • 远程操作电脑:只给“私聊 + 白名单只有你”的那只鲸鱼开工具,权限停在“只能动工作区”,越界操作在聊天里回复“批准”才执行,而且每次都要批。
  • 成本:日常聊天按本站估算一天不到 1 块钱;真正要花心思的是安全,不是钱。

一、先看懂“小鲸鱼”是怎么拼起来的

把一只聊天机器人拆开,其实就四个零件:

一只小鲸鱼的四个零件
每一行是一个零件、本文选用的组件和它的来历。都是开源项目,可以换成同类替代品。
大脑思考与调工具DeepSeek Harness(dsh):DeepSeek 官方开源的 Agent 框架,MIT 许可,“一切皆插件”。负责调用模型、管理会话、执行工具、审批权限。目前是开发者预览版,官方明说还会有不兼容的改动。
嘴巴收发消息dsh-im:社区开发者维护的 DSH 插件(MIT 许可,获得 DSH 官方 Token 赞助),一个插件接 QQ、微信、飞书、钉钉、企业微信、Telegram 等十几个渠道,扫码就能绑定。
记忆冷热分层DSH 本身不带长期记忆,靠插件补。本文推荐 dsh-fish-memory(会淡忘、带时间戳)或 dsh-mnemon(分层记忆,常用的放上下文、长期资料按需检索)。
手操作电脑DSH 自带的命令行与文件工具,配合权限预设和审批。图形界面的“计算机操作”(看屏幕、点鼠标)目前只有 macOS 的实验性提供方,本文先不用。

DeepSeek Harness · dsh-im · dsh-fish-memory · dsh-mnemon · DSH 计算机操作文档。截至 2026-11-04。

社区里那些现成的小鲸鱼呢? 比如 Frostyume/xiaojingyu 做得相当完整:有人设、心情、跨会话记忆,“规则先筛、模型后判”省 token,群友碰不到本机命令,高风险动作要主人私聊确认。它的设计思路很值得抄。但它收发 QQ 消息靠的是 SnowLuma 这类注入个人 QQ 号的方案,不是官方接口,有被风控的风险。想省心的话,先用本文的官方通道;想要“像真人群友”的体验,再去研究它。

二、准备工作

准备什么 说明
一台专门的电脑或虚拟机 DSH 官方安全说明建议用一次性虚拟机、容器或专用环境,别直接放在装着你全部资料的主力机上
Node.js 22 以上 DSH 用 npx 启动;dsh-mnemon 要求 22.19 及以上
DeepSeek API Key 去 DeepSeek 开放平台充值即用,没有订阅
一个手机 QQ、一个微信 用来扫码建机器人

先算一笔账。 DeepSeek 的 deepseek-flash(当前是 V4.1 Flash 1017)峰时每百万 token 输入 $0.30、缓存命中 $0.006、输出 $1.20,谷时再减半(官方定价)。聊天机器人的上下文大部分能命中缓存,按本站的粗略假设:

  • 每天 200 轮对话;
  • 每轮输入 4,000 token,其中八成命中缓存;
  • 每轮输出 400 token;
  • 全按峰时价算。

那么一天约 $0.15,一个月约 $4.4。让它干活(读文件、跑命令)时一轮会多调几次工具,账单会翻几倍,但量级仍然很小。

三、装大脑:DeepSeek Harness

在准备好的机器上打开终端:

npx @deepseek-ai/dsh web

浏览器会打开 http://127.0.0.1:3080,这就是 DSH 的 Web 界面。按引导填好 DeepSeek 的 API Key,先在网页里随便聊两句,确认模型能正常回复。

// 先读一遍官方的安全说明

DSH 官方 SAFETY.md 写得很直白:它没有经过安全审计,会执行模型生成的代码和命令、加载第三方插件、访问网络和文件;沙箱、审批和权限控制能降低风险,但不能保证隔离。建议用最小权限运行,放在可丢弃的环境里,并备份它能碰到的文件。下面所有关于“操作电脑”的设计,都是围绕这段话来的。

四、接 QQ 和微信:dsh-im

在启动 DSH 的那个终端里装插件(包名认准 @xmanrui/dsh-im,有同名的其他项目):

dsh plugin --profile web add -w @xmanrui/dsh-im

重启 dsh web,刷新浏览器,打开「设置 → IM机器人」。

QQ:用手机 QQ 扫码,插件会帮你在 QQ 开放平台创建一个官方机器人(也可以填已有机器人的 AppID 和 AppSecret)。私聊里它会显示“正在输入”,群聊里要 @ 它才回。

⚠ 第一件事是收紧权限。 dsh-im 的说明里写明:扫码新建的 QQ 机器人默认允许所有用户在私聊和群聊里聊天、执行内置命令。马上到机器人的访问设置里把白名单改成只有你(或你允许的人),命令权限也一起收紧。

微信:同样在设置页用微信扫码绑定。底层是腾讯开放的 iLink 个人号 Bot 接口,腾讯自己在 npm 上发布并维护了对应的微信渠道插件 @tencent-weixin/openclaw-weixin,这条路是官方的,不是逆向协议。几个现实限制:

  • 回复只有纯文本,长回复按 1,800 字分段发送;
  • 群聊支持在各方资料里说法不一,按私聊来规划最稳;
  • 登录态可能过期,需要重新扫码。

一个渠道可以接多只机器人,而且每只的工作区、模型、Agent 预设都是独立的。下文会用到这一点。

五、冷热记忆

“记忆”最常见的两种失败:一是什么都塞进上下文,很快塞满,还越来越贵;二是什么都存进数据库,结果该想起来的时候想不起来。冷热分层就是为了两头都不踩坑。

记忆的温度带
越靠左越“热”:每轮都带上,贵但随时在场。越靠右越“冷”:平时不占上下文,问到才检索,还会随时间淡忘。色带宽度只是示意。
热每轮都在 温本次会话 冷按需检索 淡慢慢遗忘
热记忆常驻人设、主人是谁、你的喜好、你们的约定。dsh-fish-memory 把这类标成“长期事实”,每轮都固定带上,不管这句话问了什么,也不会过期。
温记忆当前对话就是 DSH 会话本身的上下文。聊得太长会被压缩;想换个话题就发 /new 开新会话。
冷记忆检索过去发生的事、项目资料。dsh-fish-memory 按“命中的词够不够特别”去找,再按鲜活度、重要度、情绪排序,最多注入几条;dsh-mnemon 的做法类似,长期资料只在问题需要时才检索。
淡忘半衰期dsh-fish-memory 给每条事件记忆一个“鲜活度”,默认 30 天淡一半:不删除,只是越来越难被想起。每条都带时间,跨年了会写“去年 09-17”。

dsh-fish-memory README(插件 1.3.1 实测对应 DSH 0.2.1-rc.3);dsh-mnemon README。截至 2026-11-04。

两个插件怎么选:

  • 只想要冷热记忆,装 dsh-fish-memory:dsh plugin --profile web add dsh-fish-memory,重启后在「设置 → 鱼的记忆」里调参数。它借用你 DSH 里正在用的模型,不用另配 Key;只有“提炼”和“扩词”两步会调用模型。仓库目前没有标注标准开源许可,在意的话留意一下。
  • 想要可视化、可编辑、还能演进技能,装 dsh-mnemon(MIT 许可):在「插件 → 添加插件」里搜 dsh-mnemon。每条回复下面会列出这一轮读写了哪些记忆,点一下就能改。

装完后平时不用管:dsh-fish-memory 会按轮次自己挑值得留下的内容,每天还有配额防止塞满上下文;记了什么、哪条被想起来、为什么没被想起来,在设置页里都看得见,也能删。

装完 DSH 起不来? dsh-fish-memory 的 README 里专门写过一个坑:如果报错里有 Unexpected token、is not valid JSON,多半是 profile 目录下的 package.json 被存成了“UTF-8 带 BOM”,跟插件本身无关,去掉开头那三个字节就好。

六、远程操作电脑:只给一只鲸鱼开工具

这是最有用、也最危险的一步。危险在于:能在聊天里给它发消息的人,就能让它动你的电脑。群聊、网页内容、别人转发的文件里都可能藏着“请把某某文件发出来”之类的指令,也就是所谓的提示词注入。

所以先把鲸鱼拆成两只:

聊天鲸 管家鲸
在哪 QQ 群、微信 只在你的私聊
谁能用 群白名单 白名单只有你自己
工具 不给命令行和文件工具 给,但权限只到工作区
记忆 可以共享人设 单独一份

dsh-im 支持一个渠道接多只机器人,每只单独选工作区、模型和 Agent 预设,所以这两只可以同时挂在同一台机器上。

管家鲸的权限这样配:

  1. 权限预设停在 workspace-write。DSH 自带两档预设:workspace-write 只能写工作区目录,碰到越界操作会发起审批;danger-full-access 是完全放开、不再询问。对着聊天软件的机器人,永远不要用后者(权限预设文档)。
  2. 工作区指向一个专门的目录,比如 D:\whale-work。要它整理的文件先放进这里,别把整块盘交出去。
  3. 审批在聊天里完成。需要审批时,机器人会在原聊天里问你,你回复 批准 / 拒绝(或 同意 / 不同意 / yes / no)。Web 端和聊天两边可以同时处理,先提交的生效。dsh-im 不提供“永久批准”,每次都要你点头。这对远程操作来说是好事(dsh-im 机器人命令说明)。
  4. DSH 的审批本身是“失败即拒绝”:只有明确的“允许一次”才放行,拒绝、取消、没人应答一律不执行(审批文档)。

能让它干什么? 都是一句话的事:

  • “看一下 D 盘还剩多少空间”;
  • “把工作区里上周的 PDF 按日期改名,再打包发给我”;
  • “跑一下 npm test,把失败的那几行发我”;
  • “每天早上 9 点把昨天的日志摘要发我”。

文件可以直接回传到聊天里;私聊绑定的会话还能开“双向同步”,Web 端和定时任务的结果也会推到你手机上。

想让它点鼠标、看屏幕呢? DSH 有“计算机操作”(computer use)子系统,但官方文档里目前只有 macOS 的实验性提供方,需要单独授予辅助功能和屏幕录制权限。Windows 用户先用命令行和文件工具,覆盖面已经很大了。

七、上线前的检查清单

// 每一条都做到再让它上线
  • 白名单:扫码新建的 QQ 机器人默认对所有人开放,先改;管家鲸的白名单只留你自己。
  • 两只分开:群里那只不给命令行和文件工具,只有私聊那只有。
  • 权限:管家鲸停在 workspace-write,工作区是专门目录,绝不用 danger-full-access。
  • 隔离:最好跑在虚拟机或专用电脑上,并定期备份它能碰到的文件。
  • 密钥:API Key、机器人凭据不要放进工作区,也别让它把配置文件发到聊天里。
  • 预期管理:DSH 和这些插件都还在快速迭代,升级后可能不兼容。先在网页里测通,再放进群里。

八、它和“现成的小鲸鱼”差在哪

本文拼出来的是一个能聊天、记得事、能远程跑腿的助手,但它不会自己“潜水看气氛、挑时机插话”。社区的 xiaojingyu 在这方面下了很多功夫:规则先筛不花 token、8 秒内的消息合并成一次唤醒、有夜间静默和每日上限、有心情和精力。

想往这个方向走,可以在 DSH 里用 Agent 预设写一份人设,再参考它的“唤醒条件”和“频率上限”来调教你的聊天鲸。至于收发 QQ 消息的通道,建议仍然留在官方机器人上。

本站相关:DeepSeek 开源了自家“后厨” 讲了它官方推理引擎的事;中转站选购与验货 适合不直连官方 API、想走第三方的读者;各模型的价格和能力对比见模型天梯。
