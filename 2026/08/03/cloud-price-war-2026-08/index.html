云端在降价,本地在涨价:2026 年夏天的两个反方向

#定价策略 #竞争格局 #DeepSeek #OpenAI
目录 / Contents

  2. 二、降到了什么位置

  6. 参考文献

同一个七月,两条价格曲线朝相反方向跑:

装机的钱在涨 —— 内存三个月涨三倍,华强北一套配置一周多花两千。
调 API 的钱在跌 —— OpenAI 在 7 月 30 日把 GPT-5.6 Luna 一次砍掉 80%,距它发布才三周。

这两件事的驱动力其实是同一个,只是作用方向相反。

// 核心观点摘要
  • OpenAI 降价:7-30 Luna 砍 80%($1/$6 → $0.20/$1.20)、Terra 砍 20%($2.5/$15 → $2/$12),距 7-09 发布仅三周。
  • 降到什么位置:Luna 的输入价已低于 DeepSeek V4 Pro($0.20 对 $0.435);AA 实测跑完整套评测每题仅 $0.05,是榜上最便宜的一档。
  • 小模型在反超大模型:DeepSeek V4-Flash-0731 激活参数仅 13B,AA 指数 50,反超自家 V4-Pro 的 44。
  • 压力来源:CNBC 称中国模型已占 OpenRouter 上美国企业 token 用量的 46%。
  • 与硬件对照:云端单位智能成本在跌,本地自部署的硬件门槛在涨——"自己部署更省钱"的前提正在松动。

一、三周就降价 80%,这不正常

GPT-5.6 家族 7 月 9 日发布,Luna 定价 $1/$6、Terra $2.5/$15、Sol $5/$30。7 月 30 日,OpenAI 把 Luna 砍到 $0.20/$1.20,Terra 砍到 $2/$12。

新品上市三周就降价八成,这在任何行业都属于反常动作。上半年的主旋律其实还是涨价——GPT-5.5 的价格是 5.4 的两倍,Fable 5 定在 $10/$50。

OpenAI 官方的解释是把效率提升让利给用户,并提到模型参与重写和优化了自家生产推理代码,从而降低了服务成本。

外界的解释更直接。VentureBeat 的标题是「AI 价格战:模型竞争正转向成本」;而 CNBC 7 月 7 日的调查给出了压力的量化——中国模型已经拿下 OpenRouter 上美国企业 token 用量的 46%,一度超过美国本土模型。

二、降到了什么位置

放到本站模型天梯的口径里看更清楚:

模型 输入 $/M 输出 $/M AA 指数 AA 每任务成本
GPT-5.6 Sol (max) $5 $30 59 $2.34
GPT-5.6 Terra (max) $2 $12 55 $0.51
GPT-5.6 Luna (max) $0.20 $1.20 51 $0.05
DeepSeek V4 Pro $0.435 $0.87 44 —
DeepSeek V4-Flash-0731 $0.14 $0.28 50 —

两个值得停下来看的点:

其一,Luna 的输入价已经低于 DeepSeek V4 Pro。 $0.20 对 $0.435。这是美国前沿实验室第一次在入门档把价格压到中国开源模型之下——虽然输出端仍然更贵($1.20 对 $0.87)。

其二,每任务 $0.05 是断崖式的便宜。 同榜 Sol (max) 要 $2.34,是它的 47 倍,而指数只差 8 分(59 对 51)。对批量、可重试、容错度高的任务,这个价差足以改变架构选型。

三、另一条线:小模型正在反超大模型

7 月 31 日,DeepSeek 上线 V4-Flash-0731 正式版 API。

它最值得注意的地方不是发布本身,而是架构和体量一点没变——仍是 284B 的 MoE、每 token 激活 13B。所有提升都来自重新做的后训练:

  • Terminal-Bench 2.1 从预览版的 56.9 拉到 82.7(+25.8)
  • 原生支持 Responses API 格式,适配 Codex
  • 多项 Agent 评测反超自家的 V4-Pro 预览版

Artificial Analysis 随后收录了它:V4-Flash-0731 拿到 50 分,而 V4-Pro 只有 44 分。

一个激活 13B 的模型,打赢了同门那个体量大得多的旗舰。这条线和 Luna 降价指向同一个判断:

2026 年下半年,”参数量”和”价格档位”都不再可靠地预测能力。

看价目表选模型、看参数量选模型,都会系统性误判。这也是本站《一个模型,N 个分数》一直在强调的:同一个名字,跑法不同、版本不同,结果可以差一个量级。

四、和硬件涨价放在一起看

现在把两条曲线对齐:

方向 幅度
云端 API(入门档) ↓ 降 Luna 三周内 -80%
本地硬件(内存) ↑ 涨 DDR5 三个月 涨三倍

驱动力是同一个:AI 基础设施的爆发。 只是它对两端的作用相反——

  • 对云端:算力规模化 + 竞争白热化 → 单位推理成本下降,厂商把效率红利让出来抢份额。
  • 对本地:数据中心把上游存储产能抽干(AI 服务器 DRAM 用量是传统服务器的 8–10 倍,三大原厂七成以上先进产能倾斜给 AI)→ 消费级内存、显存反而变贵。

这直接动摇了一个流行判断:“数据敏感/量大就自己部署,长期更省钱”。

这个判断在硬件便宜时成立。但当 32GB DDR5 涨到 4.4 倍、跑得动开源大模型的显存成为稀缺品,而云端入门档已经降到每任务 $0.05 —— 自部署的回本周期被从两头拉长了:前期投入变贵,对照的云端成本变便宜。

这不是说自部署没有意义。 数据不出内网、不受额度墙限制、不担心模型下架,这些价值和价格无关。但如果你的理由只是省钱,现在值得拿真实用量重算一遍。详见《最贵装机季:AI 抢走了你的内存条》。

五、什么时候会反转

云端这轮降价能不能持续,取决于它是效率驱动还是份额驱动。

OpenAI 给的理由是效率(推理栈优化)。如果属实,降价有工程基础,不会轻易回退——这和 Anthropic 在 Opus 5 上的做法是一路的:标价不动,靠 token 效率把实际账单打下来(详见《Opus 5 一分钱没降价,但每分智能便宜了 68%》)。

如果主要是份额驱动,那就要看补贴能烧多久。考虑到 AI 基础设施资本开支仍在陡峭爬坡,这个问题在明年会更清楚。

有一个信号值得盯:如果哪天入门档开始悄悄涨回去,或者免费额度集体缩水,说明份额战打不动了。 本站的羊毛速查每次更新都会记录哪些优惠已经失效——那是一个比新闻稿更诚实的风向标。

// 风险提示
  • 本文为 2026-08-03 快照。各家定价与促销变动极快(本文主角 Luna 就是发布三周即降价 80%),以官网当期页面为准。
  • AA 指数为 v4.1 口径,与改版前分数不可直接比较;每任务成本为该机构在特定题集下的实测值,不代表你的任务成本。
  • DeepSeek V4-Flash-0731 的 Terminal-Bench 提升幅度来自厂商与第三方报道,本站未做独立复现;V4-Pro 正式版截至发稿仍未发布。
  • OpenAI 对降价原因的说明为厂商口径,外界归因(中国模型竞争压力)属分析而非事实认定。
