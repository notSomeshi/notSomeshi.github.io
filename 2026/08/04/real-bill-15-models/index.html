把 15 个模型的真实账单拉齐之后:贵 ≠ 强

#成本优化 #评测基准 #选型

我们把 15 个主流模型跑完同一套评测的实际账单逐个拉了出来,对齐之后有几个结论相当反直觉:

  • 最贵的那个(Claude Fable 5,$5,631)分数低于比它便宜 47% 的 Opus 5。
  • 标价最低的 Claude Sonnet 5($2/$10),整卷账单($4,010)比标价两倍多的 Opus 4.8($3,753)还贵。
  • 最便宜的 GPT-5.6 Luna 只花 $174,拿到 51 分——和 GLM-5.2 同分,却便宜 5 倍。
// 核心观点摘要
  • 总成本极差 32 倍:$174(Luna)→ $5,631(Fable 5),而指数跨度只有 17 分(44 → 61)。
  • 单位智能成本极差 28 倍:$3.4/分 → $93.8/分。
  • 标价完全不能预测账单:决定账单的是"话多不多"。Sonnet 5 吐了 3 亿输出 token,同类中位数只有 6,300 万。
  • 断层在底部,不在旗舰内部:旗舰档彼此差异很小(Opus 5 比 4.8 只便宜 6%),真正的数量级差距在入门档。

一、口径:为什么”同一套评测”才可比

单看 API 标价没法比较,因为不同模型完成同一件事所消耗的 token 差异巨大。推理模型会”想很久”,这些思考 token 同样按输出价计费。

Artificial Analysis 的做法是让所有模型跑同一套智能指数题集(v4.1,含 GDPval-AA v2、Terminal-Bench v2.1、SciCode、HLE、GPQA Diamond 等 9 项),按各家 API 的输入 / 缓存 / 推理 / 输出 token 逐项实际计费汇总。

下文所有数字都是 AA 官方页面逐个模型取的实测值,不是按标价推算的。 推理模型统一取厂商披露的最高 effort——这是成本上限,日常调低强度会明显更便宜。

三、标价骗人:Sonnet 5 的例子

最能说明问题的是 Claude Sonnet 5。

它的 API 标价是 $2/$10,在 Claude 全家里属于便宜档(Opus 是 $5/$25,Fable 5 是 $10/$50)。按标价推算,它跑这套题应该比 Opus 便宜一大截。

实际账单是 $4,010——比 Opus 4.8 的 $3,753 还高。

原因 AA 写得很清楚:Sonnet 5 在这套题上生成了 3 亿输出 token,而同类模型的中位数只有 6,300 万。它”话多”到把五分之二的单价优势整个吃掉了还倒贴。

单价 × 你以为的 token 量 ≠ 账单。 真实账单 = 单价 × 它实际想说多少话,而后者只能实测。

Luna 与 GLM-5.2 同为 51 分,但 $3.4 对 $18.4——差 5 倍。而旗舰档内部(Opus 5 的 $62.9 对 Opus 4.8 的 $67.0)只差 6%。

按上图总成本与 AA 智能指数折算。快照 2026-08-04。

这张图的形状说明了一件事:性价比的数量级差距发生在底部档位之间,而不是旗舰之间。

在旗舰档里纠结选 Opus 5 还是 Opus 4.8,省下的是 6%;而把一个能用 51 分完成的任务从 GLM-5.2 换成 Luna,省下的是 **80%**。

五、怎么用这张表

其一,先问任务需要几分,再挑那一档里最便宜的。 需求是 50 分,Luna($3.4/分)对 GLM-5.2($18.4/分)是压倒性的;需求是 55 分,Terra($25.5)明显优于 GPT-5.5($50.5);只有确实需要 60 分以上,才值得进 $60+/分的区间。

其二,别在旗舰档内部找性价比。 那里的差距是个位数百分比,不值得花时间比较——要么任务确实需要那个分数,要么就该往下走一整档。

其三,分层混用。 批量、可重试、容错高的任务丢给底部档;真正的攻坚才上旗舰。这也是《OpenRouter 上的权力转移》里那个”美国模型份额从 70% 跌到 30%”的成本侧解释。

其四,先调 effort 再换模型。 表中都是 max 档的上限,low→max 成本差约 3 倍。同一个模型降一档往往比换模型更省事,详见《一个模型,N 个分数》。

// 风险提示与口径边界
  • 本文为 2026-08-04 快照,数据逐个取自 AA 各模型页。AA 会随重跑更新数值,以其官网实时数据为准。
  • AA 指数为 v4.1 口径(转向智能体工作负载),与改版前分数不可直接比较。
  • 成本为 max effort 实测值,属成本上限;这是一套特定题集上的结果,不代表你的任务成本结构——你的输入输出比、缓存命中率都会显著改变结论。
  • o4-mini 与 Claude Haiku 4.5 因 AA 未公布总成本,未纳入本文比较。
  • 本文不构成任何投资或采购建议。
