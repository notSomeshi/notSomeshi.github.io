Opus 5 的降价三分之二:旗舰模型的价格战正式开打

#竞争格局 #定价策略 #Claude
目录 / Contents

  2. 二、真正的冲击在”单位智能成本”上

2026 年 7 月 24 日,Anthropic 发布 Claude Opus 5,定价 $5/$25——只有它所替代的 Opus 4.8($15/$75)的三分之一,能力却接近自家最强的 Fable 5。这不是一次常规迭代,而是旗舰档位第一次出现如此幅度的主动降价。上游的价格战,终于烧到了金字塔尖。

// 核心观点摘要
  • 降价幅度:Opus 5 $5/$25 vs Opus 4.8 $15/$75,输入输出均为三分之一。
  • 能力位置:AA 智能指数 61 分登顶,接近 Fable 5(60 分),1M 上下文。
  • 单位智能成本:约 $22.2/分,比 Fable 5($40.4)低 45%,比 Opus 4.8($62.7)低 65%——60 分档位唯一低于 $25/分的模型。
  • 结构性意义:此前"旗舰贵、中端省"的分层被打破,旗舰档自己变成了性价比选项。
  • 诱因:中国开源模型把中低端价格打穿后,压力沿着价格带向上传导。

一、这次降价有多反常

回顾 2026 年上半年的定价趋势,主旋律其实是涨价:GPT-5.5 的价格是 GPT-5.4 的两倍,Fable 5 定在 $10/$50,Gemini 3.5 Flash 是前代的三倍。西方实验室在算力成本高企、需求旺盛的背景下,普遍选择向上定价。

在这个背景下,Opus 5 的 $5/$25 显得格外突兀:

模型 输入 $/M 输出 $/M AA 智能指数
Claude Opus 4.8 $15 $75 61.4
Claude Fable 5 $10 $50 59.9
Claude Opus 5 $5 $25 60.8
GPT-5.6 Sol $5 $30 58.9

同一家公司,新旗舰比旧旗舰便宜三分之二,能力基本持平。这在传统硬件或软件行业几乎不可想象——通常新旗舰意味着新溢价。

二、真正的冲击在”单位智能成本”上

绝对价格只是表象。用本站模型天梯的”同卷不同价”口径看更清楚——跑完同一套评测,每拿到 1 分智能指数要花多少钱:

模型 评测总成本 智能指数 $/分
Claude Opus 4.8 $3,850 61.4 $62.7
GPT-5.6 Sol $2,980 58.9 $50.6
Claude Fable 5 $2,420 59.9 $40.4
Claude Opus 5 $1,350 60.8 $22.2
Gemini 3.1 Pro $1,310 56.2 $23.3

Opus 5 的 $22.2/分,让它成为60 分以上档位里唯一低于 $25/分的模型——而在它出现之前,想要 60 分级能力,最便宜的选择也要 $40/分。

这条数据的意义在于:“顶级能力必然昂贵”这个前提,第一次被自家产品线证伪了。

(必要的注脚:这些数字是在 max effort 下跑出来的,属于成本上限;实际使用中调低 effort 还能进一步压缩,详见《一个模型,N 个分数》。)

三、为什么是现在

三条线索指向同一个答案:压力是从下往上传导的。

其一,中国开源模型打穿了中低端。 如本站《OpenRouter 上的权力转移》所述,美国模型在 OpenRouter 的 token 份额一年内从约 70% 跌到约 30%,DeepSeek 单家占 16.3%。GLM-5.2、Qwen3.7、Kimi K2.6 等开源权重模型以近乎成本价供应 80 分能力,把批量任务的价格锚定在极低水平。

其二,能力差距在收缩。 前沿收敛意味着顶部几家的差距被压到几十 ELO 内。当能力不再是护城河,价格就成了主战场。

其三,推理效率的工程红利。 Anthropic 表示 Opus 5 在低档位设置上就优于早期 Opus 模型——这暗示模型本身的 token 效率有实质提升,使降价不必以毛利崩塌为代价。换句话说:这次降价有工程基础,不是纯粹的补贴换份额。

四、对不同人群意味着什么

对个人开发者:此前”能力够用就行”的妥协,现在有了新解——旗舰档的门槛降到了原来中端档的水平。如果你之前因为价格选了 Sonnet 或开源模型做主力,值得重新评估一次。

对订阅用户:Opus 5 已是 Claude Max 的默认模型,这意味着同样的 $100/$200 月费,现在能跑更多 Opus 级别的任务(因为同样的额度池下,单位任务的 token 成本降了)。用本站选购助手可以按你的实际用量重新算一遍。

对做 AI 产品的团队:毛利模型需要重算。如果你的产品定价是基于”Opus 4.8 每次调用成本”设计的,现在有了三分之二的降本空间——是让利给用户抢份额,还是转化为利润,是个战略选择。

对其他实验室:压力给到了 OpenAI 和 Google。GPT-5.6 Sol 目前 $5/$30 与 Opus 5 同价位但分数略低;Gemini 3.5 Pro 若按传闻的 $12–15/$36–45 定价发布,将处在明显不利的位置。

五、一个待观察的问题

降价能否持续,取决于一件尚不明朗的事:这是可持续的成本改善,还是一轮以份额为目标的补贴?

考虑到 AI 基础设施资本开支仍在陡峭爬坡(2026 年四巨头合计约 7,250 亿美元,详见《资本市场视角下的 AI 局势》),而 OpenAI 2026 年预计亏损约 140 亿美元,”用降价换份额”的动机是充分的。

真正的检验点在明年:当第一批天量 GPU 集中折旧、投资人开始要求兑现回报时,今天的价格能不能守住。如果守得住,AI 红利的扩散会明显加速;如果守不住,今天的低价就是又一次消费者补贴的窗口期。

// 风险提示
  • 本文数据快照为 2026-07-27,各家定价与促销变动频繁,以官网为准。
  • 成本对比基于 max effort 口径的估算值,实际使用成本受 effort 设置、缓存命中、批处理折扣影响。
  • Claude Sonnet 5 现行 $2/$10 为促销价,2026-08-31 后恢复 $3/$15,做长期成本测算时需按恢复价计。
