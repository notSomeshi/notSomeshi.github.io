Opus 5 一分钱没降价,但每分智能便宜了 68%:价格战转入 token 效率

#竞争格局 #Claude #定价策略
目录 / Contents

2026 年 7 月 24 日,Anthropic 发布 Claude Opus 5,定价 $5/$25——与它所替代的 Opus 4.8 完全相同。Anthropic 官方文档的说法是「pricing is unchanged」,Opus 档自 4.5 起就是这个价。但跑完同一套评测,Opus 5 的账单只有 Opus 4.8 的三分之一。旗舰档的价格战确实开打了,只是战场不在价目表上,而在每道题烧掉多少 token。

// 核心观点摘要
  • 标价:Opus 5 $5/$25,与 Opus 4.8 一致,Opus 档自 4.5 起未变价。官方定调是「维持原价」,不是降价。
  • 能力位置:AA 智能指数 v4.1 口径下 61 分登顶,反超 Fable 5(60 分)与 Opus 4.8(56 分),1M 上下文。
  • 真正的降本:跑完同一套 AA 智能指数评测,Opus 5 花 $1,350,Opus 4.8 花 $3,850——同样的单价、同样的题,账单少 65%,差额全部来自 token 效率。
  • 单位智能成本:约 $22.1/分,比 Fable 5($40.3)低 45%,比 Opus 4.8($68.8)低 68%——60 分档位唯一低于 $25/分的模型。
  • 结构性意义:旗舰竞争的变量从「标价」换成了「完成同一目标的总 token」。看价目表选模型会系统性误判。

一、先把事实摆正:标价一分钱没动

关于 Opus 5 的定价,市面上流传着两种互相矛盾的说法,值得先厘清:

  • 「维持原价」 —— 这是准确的。MarkTechPost 的报道标题直接写明「at Unchanged Opus Pricing」,正文是「Pricing is unchanged at $5 per million input tokens and $25 per million output tokens」。
  • 「半价」 —— 这也是准确的,但参照物是 Fable 5 而非 Opus 4.8。Anthropic 的原话是以 Fable 5 一半的价格提供接近 Fable 5 的智能;Fable 5 标价 $10/$50,一半正好是 $5/$25。The Decoder 与 Quartz 的报道都是这个口径。

把这两句话叠在一起读,很容易得出「Opus 5 比 Opus 4.8 便宜一半甚至三分之二」的结论——这是本轮报道里最常见的误读。实际的定价与能力关系是这样:

模型 输入 $/M 输出 $/M AA 智能指数(v4.1)
Claude Opus 4.8 $5 $25 56
Claude Fable 5 $10 $50 60
Claude Opus 5 $5 $25 61
GPT-5.6 Sol $5 $30 59

看清楚这张表,故事其实比「降价」更有意思:Anthropic 在标价不动的前提下,把同档产品的分数从 56 抬到 61,顺手越过了自家标价两倍的 Fable 5。 对买家而言,这等于旗舰档的「每元钱能力」凭空涨了一截,而账单上的单价数字一个没变。

二、真正的变化在 token 效率

绝对单价看不出门道。用本站模型天梯的「同卷不同价」口径看才清楚——让所有模型跑同一套 AA 智能指数题集,按各家 API 的输入、缓存、推理、输出 token 逐项实际计费:

模型 评测总成本 智能指数 $/分
Claude Opus 4.8 $3,850 56 $68.8
GPT-5.6 Sol $2,980 59 $50.5
Claude Fable 5 $2,420 60 $40.3
Gemini 3.1 Pro $1,310 46 $28.5
Claude Opus 5 $1,350 61 $22.1

关键对比是第一行和最后一行:Opus 4.8 与 Opus 5 每 token 单价完全相同,但整卷账单是 $3,850 对 $1,350。 单价既然一样,2.85 倍的差额只能来自一个地方——Opus 5 完成同样的题目少花了近三分之二的 token。

Anthropic 披露的一个细节印证了这条路径:在 GDPval-AA v2 上,Opus 5 的 xhigh 档在比 max 档少用 25% 输出 token 的同时,分数仍然高于其他所有模型。也就是说,效率提升是模型层面的实质改进,不是靠调低推理强度换来的。

Opus 5 的 $22.1/分,让它成为60 分以上档位里唯一低于 $25/分的模型——在它出现之前,想要 60 分级能力,最便宜的选择要 $40.3/分(Fable 5)。

这条数据的意义在于:「顶级能力必然昂贵」这个前提被证伪了,但证伪它的不是降价促销,而是工程效率。

(必要的注脚:表中数字都是 max effort 下跑出来的,属于成本上限;日常调低 effort 还能进一步压缩,low 到 max 的每次成本差约 3 倍,详见《一个模型,N 个分数》。)

三、为什么是现在

三条线索指向同一个答案:压力是从下往上传导的,只是传导到旗舰档时,表现形式从「降价」变成了「同价加量」。

其一,中国开源模型打穿了中低端。 如本站《OpenRouter 上的权力转移》所述,美国模型在 OpenRouter 的 token 份额一年内从约 70% 跌到约 30%,DeepSeek 单家占 16.3%。GLM-5.2、Qwen3.7、Kimi K2.6 等开源权重模型以近乎成本价供应中端能力,把批量任务的价格锚定在极低水平。2026 年 7 月 27 日 Moonshot 放出 Kimi K3 的 2.8 万亿参数开源权重(史上最大,商用需另签授权),又把这条线往上顶了一截。

其二,能力差距在收缩。 前沿收敛意味着顶部几家的差距被压到几十 ELO 内。当能力不再是护城河,成本效率就成了主战场。

其三,旗舰档降不动标价,只能降 token。 这是最关键的一条。旗舰的毛利要覆盖训练摊销,直接砍标价会立刻传导到财报;而提升 token 效率既能降低客户实际支出,又不动价目表——对厂商是更优的竞争手段。Opus 5 正是这条路线的样本:标价维持,实际账单腰斩还多。

四、对不同人群意味着什么

对个人开发者:此前「能力够用就行」的妥协有了新解——不是旗舰降价了,而是同样的预算能跑完更多旗舰级任务。如果你之前因为账单选了 Sonnet 或开源模型做主力,值得按实际 token 消耗重新算一次。

对订阅用户:Opus 5 已是 Claude Max 的默认模型。由于额度池按 token 计,而 Opus 5 完成同样任务耗的 token 更少,同样的 $100/$200 月费实际能做的事变多了。用本站选购助手可以按你的用量重新评估。

对做 AI 产品的团队:如果你的毛利模型是按「Opus 4.8 每次调用的 token 量」估的,现在有实质降本空间——但注意降本来源是 token 数而非单价,所以幅度取决于你的任务形态:推理密集、返工多的任务受益最大;短问答类几乎没变化。别直接把 65% 抄进财务模型,要用自己的真实 trace 重算。

对其他实验室:压力给到了 OpenAI 和 Google。GPT-5.6 Sol 标价 $5/$30 与 Opus 5 基本同档、分数 59 略低,但整卷成本 $2,980 是 Opus 5 的 2.2 倍——差距主要在话多。Gemini 3.1 Pro 的处境更尴尬:v4.1 口径下只有 46 分,却要 $28.5/分。

五、一个待观察的问题

效率红利能否延续,取决于一件尚不明朗的事:token 效率的提升是可复制的工程能力,还是一次性的架构收益?

单价不变的降本比补贴降价更健康——它不依赖厂商让利,因此不会因为融资环境变化而回退。但它也有天花板:token 效率不可能无限压缩,当效率红利吃完,如果能力竞争仍未拉开差距,标价战恐怕还是躲不过。

考虑到 AI 基础设施资本开支仍在陡峭爬坡(2026 年四巨头合计约 7,250 亿美元,详见《资本市场视角下的 AI 局势》),而 OpenAI 2026 年预计亏损约 140 亿美元,真正的检验点在明年:当第一批天量 GPU 集中折旧、投资人开始要求兑现回报时,今天这种「同价加量」还给不给得起。

// 风险提示
  • 本文数据快照为 2026-07-30,各家定价与促销变动频繁,以官网为准。
  • AA 智能指数为 v4.1 口径(转向智能体工作负载),与改版前的旧分数不可直接比较;跨版本引用他处分数时务必核对口径。
  • 成本对比基于 max effort 口径,属成本上限;实际成本受 effort 设置、缓存命中、批处理折扣影响。「同卷总成本」中除 Kimi K3($2,709.75)等实测锚点外为折算估算值。
  • 「省 65%」是 AA 这套特定题集上的结果,不等于你的任务也能省 65%——受益幅度取决于任务的推理密度。
  • Claude Sonnet 5 现行 $2/$10 为促销价,2026-08-31 后恢复 $3/$15,做长期成本测算时需按恢复价计。
  • 本文不构成任何投资或采购建议。
