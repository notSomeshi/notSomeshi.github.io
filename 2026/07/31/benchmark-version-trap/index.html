榜单换了把尺子,我全站的分数一夜作废

#评测基准 #数据方法 #Artificial Analysis
目录 / Contents

  2. 二、错误是怎么串成一串的

维护这个站点的模型天梯时,我踩了一个不算冷门、但后果很大的坑:Artificial Analysis 的智能指数升级到了 v4.1,全部模型重新打分,而我沿用的还是改版前的旧值。

结果是,天梯上 20 个模型的 AA 指数列整列失真,其中 Claude Opus 4.8 被标成 61.4 分——它在新口径下的真实分数是 56。这个错误还连带让一整篇文章的论点站不住脚。

本文记录这次修正,以及一条对所有引用榜单数据的人都适用的教训。

// 核心结论
  • 基准会升版,升版会重算全部分数——AA 的 v4.1 把题集换成了偏智能体的九项,新旧分数不可直接比较。
  • 本站受影响的幅度:Opus 4.8 61.4→56、Gemini 3.1 Pro 56.2→46、o4-mini 43.5→26、Mistral Large 3 40.2→16;也有上调的,GLM-5.2 48.3→51、Sonnet 5 51.2→53。
  • 排序都会变:旧数据里 Opus 4.8 压着 Opus 5,修正后 Opus 5 以 61 分反超五分登顶。
  • 教训:引用榜单分数时,版本号和抓取日期必须一起记,否则半年后没人知道那个数字是什么口径。

一、v4.1 改了什么

Artificial Analysis 的智能指数是把多项基准合成一个 0–100 数字的综合指标。v4.1 的方向是转向智能体工作负载,题集为九项:GDPval-AA v2、τ³-Banking、Terminal-Bench v2.1、SciCode、Humanity’s Last Exam、GPQA Diamond、CritPt、AA-Omniscience、AA-LCR。

关键在于:换题集之后,所有模型都要重跑。一个在旧题集上擅长静态问答的模型,在偏智能体、偏工具调用的新题集上可能明显掉分。这不是模型变差了,是尺子换了。

掉得最狠的几个很能说明问题:

模型 旧口径 v4.1 变化
Mistral Large 3 40.2 16 -24.2
o4-mini 43.5 26 -17.5
Gemini 3.1 Pro 56.2 46 -10.2
Claude Opus 4.8 61.4 56 -5.4
GLM-5.2 48.3 51 +2.7
Claude Sonnet 5 51.2 53 +1.8

非推理模型(Mistral Large 3、o4-mini)掉幅最大——新题集对智能体能力的权重上来了,它们没这个能力。而 GLM-5.2 这类持续迭代的开源模型反而上调。

二、错误是怎么串成一串的

单个数字错了不可怕,可怕的是它会往下游传。这次的传导链是这样的:

第一层,排序错了。 旧数据里 Opus 4.8(61.4)高于 Opus 5(60.8),天梯呈现的是”旧旗舰仍是分数王”。修正后 Opus 5 是 61、Opus 4.8 是 56,Opus 5 反超五分登顶。

第二层,派生指标错了。 本站成本图有一列”每 1 分智能的成本”= 总成本 ÷ 指数。分母错了,这一列就整列错。Opus 4.8 的单位智能成本从 $62.7/分 变成 $68.8/分。

第三层,文章论点错了。 我写过一篇讲 Opus 5 定价的文章,标题是《Opus 5 的降价三分之二》,核心论点是”新旗舰比旧旗舰便宜三分之二”。这里其实叠了第二个独立错误:Opus 4.8 的标价从来就是 $5/$25,和 Opus 5 一模一样。

这个错误的来源很典型——把两句都正确的话拼错了参照物:

  • MarkTechPost 的报道标题写得很清楚:「at Unchanged Opus Pricing」,正文是「Pricing is unchanged at $5 per million input tokens and $25 per million output tokens」。
  • The Decoder 和 Quartz 说的”半价”,参照物是 Fable 5 的 $10/$50,不是 Opus 4.8。

把”半价”挂到 Opus 4.8 头上,就得出了”降价三分之二”这个不存在的结论。这篇文章已经重写并加了更正说明——有意思的是,修正后的故事反而更值得写:标价一分没动,但跑完同一套评测的账单从 $3,850 降到 $1,350,省的全是 token 而不是单价。

三、给引用榜单数据的人的三条建议

其一,记版本号,不只记日期。 “AA 指数 61 分”是不完整的信息,”AA 智能指数 v4.1,2026-07-31 抓取,max effort”才是。基准升版的频率比多数人以为的高。

其二,注意 effort / 配置后缀。 AA 的条目名里 (max)、(high)、(xhigh) 是推理强度设置,不是产品型号。我另一个错误就是把 “DeepSeek V4 Pro (max)” 当成了一个叫 “V4 Pro Max” 的产品写进榜单。同一个模型的不同 effort 会被列为独立条目,分数和成本都不同。

其三,跨版本比较是无效的。 如果你手上有半年前记的分数,不要和今天的新分数放同一张表里比。要么整列重取,要么明确标注版本不同。这次我采取的是前者——20 个模型逐个重新核对。

// 风险提示
  • 本文所有 v4.1 分数为 2026-07-31 从 Artificial Analysis 逐个模型页面核对所得,均取厂商披露的最高 effort 设置。以 AA 官网实时数据为准。
  • "旧口径"分数为本站改版前记录值,其原始抓取时点已不可考,仅用于展示变化幅度,不应作为任何历史版本的权威引用。
  • GPT-5.5 Pro 在 AA 尚无收录成绩,本站该项标记为缺失而非估值。
  • 综合指数是多项基准的合成量,不能代表模型在你具体任务上的表现。

一个附带的判断

这件事让我对”综合指数”这类合成指标更谨慎了一点。它的优点是一个数字就能排序,缺点也正是这个——它把方法论的变化藏进了一个看起来很稳定的数字里。分数从 61.4 变成 56,页面上只是两个字符的差别,但背后是整套评测哲学的转向。

所以现在本站天梯的每个机构列都保留原始分数而不是只给综合分,并且把口径说明写在旁边。想看模型在你关心的那一类任务上的表现,点开单项比看综合分靠谱得多。
