零成本用上 AI:2026 年 7 月的羊毛地图

#成本优化 #免费额度 #入门

刚入门的人最常问的不是”哪个模型最强”,而是”我不想先掏钱,能不能先用起来”。答案是能——而且能用得相当好。本文把 2026 年 7 月还有效的免费额度整理成一张地图,按你是谁分四条路,每条路都能做到月支出为 0。

// 四条零成本路径
  • 学生 / 教师 / 开源维护者 → GitHub Copilot 认证后 Pro 全额免费,门槛最低的一条。
  • 国内用户 → 腾讯元宝接入混元 Hy3 后 Agent 功能全免费,一句话直出 PPT / Word / Excel。
  • 会配 API 的 → 免费开源外壳(Cline / n8n)+ 国产永久免费模型,长期成本压到接近 0。
  • 只想试水 → Cursor Hobby、Copilot Free、Trae Free 都是不限时的永久免费档。

一、学生党:目前最划算的一张身份牌

GitHub Copilot 对学生、教师和开源维护者提供全额免费的 Pro,通过 GitHub Education 认证即可。Pro 档包含不限量代码补全和约 300 次高级请求/月,背后能调 GPT-5.6、Claude Sonnet 5 和 Gemini 系列——这已经是前沿模型的水平。

Anthropic 那边有 Claude Campus,校园 Builder Clubs 共享 $50 学生 API credits,额度不大但可以用来试 Claude Code。

一个已经关掉的窗口:Cursor 的学生免费 Pro 年已于 2026-06-25 停止新注册,老用户不受影响。这也是本文要强调的第一件事——羊毛是会消失的,看到合适的就去领。

二、国内用户:元宝的 Agent 是目前最实在的免费档

7 月 6 日腾讯发布混元 Hy3 正式版并开源(295B MoE、激活 21B、256K 上下文),元宝第一时间接入并同步上线 Agent 能力,且全部免费。

它的实际意义比”免费聊天”大得多:你在对话里提需求,元宝可以直接执行任务并交付 PPT、Word、Excel、PDF、HTML 文件。对于日常办公场景,这已经覆盖了 Microsoft 365 Copilot 的一大半用途——而后者对个人用户根本没有免费层,新客户实际落地成本约 $59–83/席/月。

同属腾讯的 WorkBuddy 是这一轮里免费积分渠道最多的一家:

渠道 数量
体验版月度赠送 500 积分/月(永久)
代码补全 5,000 次/月
新用户注册 3,000+ 积分(90 天内有效)
每日签到 第 1–6 天各 100,第 7 天 1,000
邀请好友 500/人
成长任务 700–900

叠起来之后,轻度用户基本不用付费。但要注意:WorkBuddy 所属的腾讯系产品一年内涨了三次价,企业旗舰版 2026-05-15 从 78 元涨到 198 元/人/月(+154%)。免费档慷慨和付费档涨价是同时发生的,别把长期规划压在它身上。

三、会配 API 的:免费外壳 + 免费模型

这是长期成本最低的一条路,代价是要自己动手配一次。

外壳选免费开源的:Cline / Roo Code 是开源 VS Code 插件,插件本身永久免费,你付的只是所选模型的 API 费;n8n 自托管后彻底没有 credits 概念,成本只剩服务器和模型 API。

后端接国产永久免费模型:混元 Lite、智谱 GLM Flash 系列都提供永久免费调用。再叠加各家的新用户赠量——阿里云百炼每个模型约 100 万 token(约 90 天)、智谱新用户实名约 2,000 万 token、火山引擎方舟的体验额度与按天重置的协作奖励——日常量级的使用可以做到接近零成本。

组合起来就是:免费的编辑器插件 + 免费的模型 API = 一个能用的 AI 编程环境,月支出 0。能力当然不如 Opus 5,但对学习、写小工具、做课程项目完全够用。

四、只想试水:哪些免费档是”不限时”的

区分永久免费档和限时促销很重要:

  • 不限时的:Cursor Hobby(约 2,000 次补全 + 50 次慢速高级请求/月)、GitHub Copilot Free(2,000 次补全 + 50 次 chat/月)、Trae Free(少量快速请求,用尽转慢速队列但不额外收费)。
  • 不要指望的:Google Antigravity 公测期免费额度看着大,但上线时 250 请求/天,到 2025-12 已砍到 20 请求/天,降幅 92%,且 Google 未承诺永久免费层。可以薅,别当主力。
// 风险提示
  • 本文为 2026-07-31 快照。羊毛政策变动极快——半年内 Cursor 停了学生免费、Antigravity 砍了 92% 额度、腾讯系涨了三次价。领取前务必以官网当期页面为准。
  • 部分平台的赠送额度数字来自第三方汇总,各来源口径不完全一致,已尽量标注"约"。以官方控制台显示为准。
  • 免费额度通常伴随更低的并发、更慢的队列、更小的上下文,不适合承载生产业务。
  • "永久免费"是厂商当前的承诺,不是合同义务,随时可能调整。

最后一句实话

免费额度能解决”入门”和”学习”,解决不了”生产”。等你真的开始用 AI 干活、并且撞到额度墙的时候,再去看模型天梯的订阅性价比板块算账不迟——那时候你已经知道自己每月实际烧多少 token 了,比现在凭感觉选套餐准得多。

顺带一提,先调低推理强度再考虑换便宜模型,往往比直接降级模型更省钱,详见《一个模型,N 个分数》。
