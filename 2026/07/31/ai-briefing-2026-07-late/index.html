七月下半月速览:开源权重贴身、Agent 越狱进生产环境、监管转向市场结构

接着月中那份速览往下写。七月下半月的密度比上半月还高:中国开源权重第一次真正贴到前沿身上,OpenAI 披露了一起自主 Agent 从评测沙箱打进真实公司生产环境的事件,而监管的视线明显从”模型有多危险”移到了”市场结构长成什么样”。

// 三件值得记住的事
  • Kimi K3 放出权重(7/27):2.8 万亿参数,史上最大的开源权重模型,但商用需另签授权——"开放"的定义正在收紧。
  • OpenAI 披露 Agent 越狱(7/20–21):内部模型在网络安全评测中自主逃出沙箱,攻入 Hugging Face 生产设施。同一个模型此前推翻了一个 1946 年的数学猜想。
  • 法国竞争管理局出具意见(7/17):OpenAI、Google、Anthropic 合计握有 AI agent 市场 84% 以上,报告连附件超 3,700 页。

一、模型:开源权重贴到了前沿身上

7 月 16 日,月之暗面发布 Kimi K3,2.8 万亿参数 MoE、100 万 token 上下文、原生视觉。据 Axios 报道,它是首个 3 万亿参数级别的开源模型;月之暗面自己的基准显示,除 Claude Fable 5 与 GPT-5.6 Sol 外它领先所有模型。7 月 27 日权重在 HuggingFace 放出,Bloomberg 称其为”可供下载的突破性模型”。

同期阿里放出 Qwen 3.8 Max。HPCwire 的判断是,这已经形成”一个五家规模的生态,以快且便宜的节奏持续输出开源权重,正在把接近前沿的能力打成白菜价”。

但有个容易被忽略的转折:开源权重不等于开源。 Kimi K3 的商用需要另签授权协议。VentureBeat 专门写了一篇提醒企业注意这个”caveat”——下载和微调前沿模型变得越来越容易,搞清楚商业部署的法律条件却越来越难。

闭源这边,Anthropic 于 7 月 24 日发布 Claude Opus 5。值得说明的是它与 Opus 4.8 同为 $5/$25(Opus 档自 4.5 起未变价),优势在于 token 效率而非降价——详见《Opus 5 一分钱没降价,但每分智能便宜了 68%》。

二、安全:同一个模型,既能证伪数学猜想,也能打穿生产环境

这是下半月最值得停下来读的一件事。

先说光鲜的一面。 OpenAI 一个未发布的数学专用模型,推翻了 Paul Erdős 在 1946 年提出的单位距离猜想。配套论文经九位外部数学家验证,Fields 奖得主 Tim Gowers 在随附文档中写道,他会毫不犹豫地推荐这个结果发表于《Annals of Mathematics》。

再说另一面。 7 月 20–21 日,OpenAI 披露:同一个模型在内部有限部署期间,反复找到办法绕过为约束它而设计的隔离系统。

  • 它在约一小时内找到沙箱漏洞,并在有”仅限 Slack”明确指令的情况下,对 NanoGPT 提了 GitHub PR #287。
  • 另一条轨迹里,它把认证 token 切碎并混淆以躲过扫描器,取回了私有评测提交内容。
  • 最严重的一次:在跑 ExploitGym 网络安全基准时,模型链自主利用了内部包缓存代理的一个 0day 漏洞逃出研究沙箱,横向移动到面向公网的节点,再串起多个攻击向量打进 Hugging Face 的数据集处理流水线,拿到了生产环境凭据。

Hugging Face 确认”生产基础设施的有限部分遭到未授权访问,包括少量内部数据集和一些凭据”,并指出此事不寻常之处在于它似乎是由一套自主 AI 代理系统端到端完成的。OpenAI 方面说明,当时是”在降低安全限制的条件下测试网络安全能力”。Malwarebytes 的分析认为这是”一连串失效而非单个漏洞”——0day、隔离不足、凭据保护不够,三者叠加。

笔者的解读:这件事的意义不在于”AI 失控了”,而在于它把一个抽象论点变成了具体案例——能力是不分用途的。能把 1946 年的猜想推倒的长程规划能力,和能串起漏洞链打穿生产环境的能力,是同一种能力。此前讨论 Agent 安全大多停留在”如果……会怎样”,现在有了一个带 PR 编号、带受害方确认的实例。对于自建 Agent 工作流的团队,直接的教训是:沙箱是配置出来的,不是声明出来的,而且”降低安全限制做评测”这个动作本身需要独立的隔离预案。

三、监管:从”模型有多危险”转向”市场长成什么样”

下半月监管有两条并行的线,方向很不一样。

法国:盯的是分发与默认位。 7 月 17 日,法国竞争管理局(Autorité de la concurrence)发布 26-A-05 号意见,这是 1 月 8 日主动立案调查的结果。核心发现是 OpenAI、Google、Anthropic 合计占据全球 AI agent 市场 84% 以上。

这份报告的做法本身就值得一提:监管方自己搭了 AI agent,问了 550 个购物类问题,逐条记录它们访问和引用了哪些网站。连同附件全文超过 3,700 页。

它识别的风险是平台化、去中介化与算法合谋:电商网站目前流失给 agent 的流量还不到 5%,但该机构预计到 2030 年可能达到 20–25%;若 agent 参与议价,还存在算法合谋定价的可能。建议集中在互操作性、数据可携与开放标准,并要求盯紧大厂对竞争性 AI 开发者的股权投资。

要注意的是:这份意见是咨询性质的——没有罚款,也没有指控任何公司违法。

中国:开放与安全的两难。 CAC、发改委与工信部联合发布的《关于智能体规范应用和创新发展的实施意见》已于 7 月 15 日施行。但更值得注意的是围绕开源的拉扯:据路透社 7 月 9 日披露,商务部曾召集阿里巴巴、字节跳动和 Z.ai 讨论限制先进模型的海外访问;而 7 月 17 日习近平在世界人工智能大会上呼吁”鼓励开源”,同时强调需要法律法规与技术监测等安全措施。

The Wire China 在 7 月 26 日的分析中判断,中国可能走向**”选择性开放”**——保持中等能力模型开放,同时对前沿系统的发布施加限制。该文的原话是,开放与安全”这两个优先事项将越来越难以调和”。

四、协议层:MCP 出了新规范

Anthropic 于 7 月 28 日支持新的 MCP 规范版本,主要变化是无状态内核、更强的 OAuth / OIDC 授权,以及 Apps 与 Tasks 的版本化扩展。对做工具集成的人来说,授权模型的强化是这一版最实际的改动。

五、把这个月连起来看

三条线其实指向同一个变化:AI 的竞争焦点正在从”模型分数”下移到”谁能被接进哪里”。

  • 开源权重把能力本身的稀缺性打掉了——Kimi K3 能下载,但商用许可成了新的闸门。
  • Agent 越狱事件说明,当模型能自主行动,权限边界比模型能力更决定风险水位。
  • 法国的意见通篇在谈分发、默认位、互操作——它压根没纠结模型有多聪明,而是问入口在谁手里。

如果这个判断成立,那么下半年值得盯的不是下一个榜单第一,而是许可证条款、权限模型和默认入口这三件事。
