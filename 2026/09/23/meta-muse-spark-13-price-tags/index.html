Meta 给同一个模型开了四种价,其中一种用数据付

Meta 在 2026-09-02 发布了 Muse Spark 1.3。

官方的说法很克制:更能扛长任务、更愿意在提示含糊时反问、编程场景下比 1.2 少用约 20% 的工具调用和 25% 的 token。没有”史上最强”之类的措辞。

真正值得看的不是模型本身,是它的价目表。

同一个 Muse Spark 1.3,Meta 开了四个入口,每个入口用不同的单位收钱。
按 token 卖、按"Muse token"周额度卖、按"每 5 小时多少条提示"卖、按社交 App 的增值功能卖。你得先决定用哪种货币买它。

先说它在榜上的位置

这是能查证的部分。

Artificial Analysis 的智能指数(v4.3.2)给它 48 分;跑完整套评测花 $2,000,折合 $41.7 / 分。

45 分以上的模型,每 1 分智能要花多少钱
柱长按最贵的 Claude Fable 5.1($247.7/分)归一。口径:跑完同一套 AA 智能指数题集的总成本 ÷ 智能指数,推理模型均取厂商披露的最高 effort 档。
Muse Spark 1.348 分 $41.7/分
GLM-5.345 分 $55.6/分
GPT-5.6 Sol47 分 $73.7/分
GPT-6 Astra53 分 $100.5/分
Claude Opus 551 分 $142.6/分
Claude Fable 5.153 分 $247.7/分

分数与成本逐个取自 Artificial Analysis 各模型页(v4.3.2)。快照 2026-09-22。

在 45 分以上这一档里,它是每分智能最便宜的一个。 不是最强,但把”分数除以账单”这件事做得最好看。

LiveBench 当前版本给它 81.6,Arena 1493。三家都有数,所以它进了模型天梯。

四个入口,四种计价单位

入口 价格 计价单位
Meta Model API $1.25 / $4.25(缓存命中 $0.15) 每百万 token
Meta Model API 贡献者档 $0.10 / $0.20(缓存 $0.002) 每百万 token
Muse(个人助手) 免费档 / Power $20 / Maximum $100 每周多少个「Muse token」
Muse Code(终端编程) $5 / $15 / $50 每 5 小时多少条提示
Meta One Core $7.99 / Premium $19.99 社交 App 功能 + 图片视频生成额度

这五行里有三个坑,挨个说。

第一,Meta One 不是聊天套餐。 它 09-15 上线,看起来像”Meta 版 ChatGPT Plus”,实际买的是 Instagram、WhatsApp、Facebook 的增值功能,以及用 Muse 模型生成图片和视频的额度。官方的措辞是”更多媒体生成”,通篇没提 Muse Spark 的对话额度。

第二,Muse 的”Muse token”是 Meta 自定的单位。 Power 档每周 5 亿、Maximum 档每周 30 亿,听着很多,但官方没公布它和模型 token 的换算关系。没有换算关系,就没法和 $20 的 ChatGPT Plus 做比较——这也是本站的性价比表里把它的”折算价”一栏留空的原因:算不出来就不填。

第三,Muse Code 的价格和额度口径对不上。 $5 / $15 / $50 这组价格出自 1.2 时代的发布博客,当时写的是 High 档 3 倍、Power 档 10 倍额度;而现在的官方文档已经改成 5 倍和 20 倍,并且不再标价格。额度翻倍了,价格有没有跟着动,官方没说。

那个便宜十二倍的档位

真正有意思的是 API 的两档。

标准档 $1.25 / $4.25。贡献者档 $0.10 / $0.20。

输入便宜 12.5 倍,输出便宜 21 倍,缓存命中便宜 75 倍。

差别只有一条,官方写得很直白:贡献者档的提示词和输出会被用于改进 Meta 的产品,标准档不会。

⚠ 这不是"免费额度",是一笔明码标价的交易。
你省下的每一块钱,对价是你送进去的内容。做商业项目、处理客户数据、或者签过保密条款的场景,先把这一条读完再决定。

值得停下来想一秒的地方

Meta 过去在这件事上是另一种打法。

Llama 系列靠放出权重换生态:你随便下载、随便自部署,Meta 拿到的是事实标准的地位和整个开源社区的改进。

Muse Spark 不是这样。Artificial Analysis 的模型页写得清楚:它是闭源的,权重不公开。

于是同一家公司,在两代产品上用了两种完全不同的方式换同一样东西:

  • Llama 时代:给你权重,换生态位
  • Muse Spark 时代:给你折扣,换你的数据

从”送东西换影响力”变成了”打折换数据”。 对用户来说,后者的账更好算——便宜多少是明码标价的;但也更直接:你交出去的是自己的内容,而不只是安装一个开源模型。

这个转向不是 Meta 独有的。但把”用数据换低价”做成 API 定价表上一个可以勾选的档位,做得这么干脆的,目前还不多见。

对中国大陆读者的现实

得说清楚:这四条线目前都不对中国大陆开放。

Meta Model API、Meta One 都不在可用地区;Muse 个人助手更窄,目前只在美国(iOS、Android、muse.ai),而且订阅本身还在小范围测试阶段。

所以如果你在国内,这篇的实际价值是参照系而不是选项:它给出了”48 分的模型可以卖到多便宜”的一个基准,拿去对照选购助手里那些能直连的方案。

怎么看

  • 想要便宜的 48 分:如果你人在可用地区、且用途不涉及敏感内容,贡献者档确实是这个分数段里罕见的价格。先读数据条款,再算账。
  • 想要稳定的编程工作流:Muse Code 的价格口径当前是模糊的,别按 $5/$15/$50 做长期预算,以订阅页当期显示为准。
  • 看到”Meta One 含 AI”就以为能聊天:不是。那是图片视频生成和社交功能。
